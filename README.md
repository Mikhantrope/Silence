# SILENCE — как запустить

Сайт использует `fetch()` (форма заявки, аналитика) и `@font-face`/`data-theme`,
поэтому открывать `index.html` двойным кликом (`file://`) не стоит — часть
браузеров режет такие запросы. Нужен локальный HTTP-сервер, это одна команда.

## Быстрый способ

**Windows:** дважды кликните `start.bat`.
**macOS/Linux:** дважды кликните `start.sh` (если не запускается — в терминале
`chmod +x start.sh && ./start.sh`).

Скрипт сам найдёт свободный порт (8080–8090), поднимет сервер и откроет
`http://localhost:<порт>/index.html` в браузере. Окно терминала держите
открытым, пока пользуетесь сайтом; закрыть — `Ctrl+C`.

Единственное требование — установленный Python (есть почти везде по
умолчанию на macOS/Linux; на Windows — https://www.python.org/downloads/,
при установке отметить «Add to PATH»).

## Вручную, если Python не хочется

Подойдёт любой статический сервер из корня папки `silence/`, например:

```
npx serve .
```

или встроенный сервер VS Code («Live Server»).

## Что не будет работать локально

Кнопка «Отправить» на `contacts.html` шлёт `fetch()` на `/api/lead` —
такого адреса на локальном статическом сервере нет, поэтому форма честно
покажет «Не удалось отправить». Это нормально: реальная отправка появится,
когда `js/config.js` укажет на настоящий приёмник заявок (сейчас там
осознанно пусто — см. отчёт по Шагу 13/14).

Калькулятор цены на главной скрыт по той же логике: `js/data.pricing.js`
пока без тарифов (`ready: false`).
